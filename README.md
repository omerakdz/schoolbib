# SchoolBib

Een simpele C# applicatie voor het oefenen van objectgeoriënteerd programmeren.

## Over dit project

Dit project bevat basisfunctionaliteit om belangrijke C# concepten te oefenen, zoals:

- **Klassen en objecten** - Het werken met klassen en het instantiëren van objecten
- **Methodes** - Het definiëren en aanroepen van methodes
- **Objectgeoriënteerd programmeren (OOP)** - Het toepassen van OOP-principes
- **Programmeerlogica** - Het schrijven van logische code-structuren

## Doelstelling

Dit project is bedoeld als leermateriaal om fundamentele C# programmeerconcepten praktisch toe te passen en beter te begrijpen.

## Technologie

- **Taal**: C#
- **Type**: Console applicatie / Leerproject

*Dit is een educatief project voor het verdiepen van C# kennis.*
